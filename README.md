All six featured projects are verified against authentic repositories and code architectures:

1. **01 // Traffic Counting & Vehicle Categorization Pipeline**
   - *Domain*: Computer Vision & Deep Learning
   - *Stack*: Python 3.12, Ultralytics YOLOv8, ByteTrack, OpenCV, CustomTkinter, Flask, Pandas
   - *Highlights*: Vector cross-product line crossing mathematics (`ccw` test), occlusion resilience, zero external cloud dependencies.
2. **02 // Temple ERP — Enterprise Community & Financial General Ledger**
   - *Domain*: Enterprise Systems & Native Desktop
   - *Stack*: FastAPI, React 19, Tauri v2, TypeScript, Tailwind CSS, SQLAlchemy 2.0, SQLite & PostgreSQL
   - *Highlights*: Offline-first native desktop shell (<20MB), automated Masavari monthly compounding dues, counter shift cash drawer reconciliation.
3. **03 // Retail & Enterprise Business Automation Suite**
   - *Domain*: Robotic Process Automation & Computer Vision
   - *Stack*: Python 3.12, CustomTkinter, Tesseract OCR, Selenium WebDriver, PyAutoGUI, FPDF2, MS SQL Server
   - *Highlights*: 5-microtool suite including eSSL biometric wage calculation, OCR-driven POS keyboard lockout for restricted debtors, automated WhatsApp remittance RPA.
4. **04 // STM32 HydroSense — Embedded Telemetry & Water-Level Monitor**
   - *Domain*: Embedded Systems & Firmware
   - *Stack*: STM32F103C8T6 (ARM Cortex-M3), Embedded C, STM32Cube HAL, I2C, SH1106 OLED (128x64), FreeRTOS
   - *Highlights*: Rolling median filter with 3% hysteresis, DMA-driven SH1106 framebuffers, galvanic probe pulse excitation.
5. **05 // GestureSense — Vision-Based Real-Time Hand Landmark Controller**
   - *Domain*: Human-Computer Interaction & AI
   - *Stack*: Python 3.12, Google MediaPipe, OpenCV, PyAutoGUI, NumPy

6. **06 // Krishi Sakhi — Multimodal Gemini AI & Telephony Gateway**
   - *Domain*: Applied Multimodal AI & Telephony
   - *Stack*: Google Gemini 1.5 Flash API, Twilio Voice IVR, Node.js, Express, Android WebView
   - *Highlights*: Accessible voice hotline for smallholder farmers, botanical leaf disease diagnosis.

## ✦ Development & Production Commands

Run using standard commands from the `portfolio/` directory:

```bash
# Install dependencies
npm.cmd install

# Start local development server (port 5173)
npm.cmd run dev

# Build production bundle
npm.cmd run build

# Preview production build locally
npm.cmd run preview
```
